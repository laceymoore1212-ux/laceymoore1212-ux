# DreamWorld Pocket Lab | Roblox game prototyping and playtest learning

## Concept
DreamWorld Pocket Lab is a private, owner-controlled Roblox game development and playtesting experiment with an Android-first usability emphasis.

## Documented development history
- **v0.13:** Published and tested on Android; core functionality did not meet expectations.
- **v0.14:** Later published and owner-tested. Accessibility improved, but key playability and visual goals remained unmet.
- **v0.15 candidate:** A playability-focused rebuild passed static validation in a development environment. **It was not yet published or confirmed through Roblox Studio or a hands-on Roblox playtest** at the latest recorded review.

## Areas under evaluation
- Clear onboarding and tutorial flow.
- Navigation and touch controls.
- Visual readability and user interface discoverability.
- Game progression, rewards, shop interactions, emotes and obby gameplay.
- Reliable packaging, validation, publication gates and rollback planning.

## Development lesson
One purpose of this experiment is to show that software generated with AI still needs real human playtesting. A passing static check is not a playable game. Every release candidate needs a test plan, a recorded outcome, and honest failure reporting.

No live gameplay link or polished gameplay screenshot is claimed here until a public build can be independently verified.
